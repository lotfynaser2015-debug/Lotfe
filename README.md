## CPR
القائمة → **📈 CPR (تجريبي/حقيقي)**

1. اختر الوضع: 🧪 تجريبي أو 💰 حقيقي
2. حدد رأس المال + حجم الصفقة + العملات (حتى 20+)
3. تشغيل → دخول عند كسر فوق TC | خروج عند R1 أو كسر BC
4. **📊 النتائج**: صفقات، ربح/خسارة، نسبة نجاح

التجريبي لا يرسل أوامر MEXC — للمتابعة والتقييم فقط.

لوجات: `[CPR]`
