# Lotfe — MEXC Spot Telegram Bot

إدارة محافظ + متابع **SuperTrend** الحقيقي من شموع MEXC.

## SuperTrend
القائمة → **📈 SuperTrend**

- حساب المؤشر من OHLCV (ATR + مضاعف) — مش تخمين
- **يدوي:** شغّل المتابع ثم أرسل رمز العملة (مثال SEI)
- **تلقائي:** فعّل التلقائي + سلة عملات → دخول عند إشارة شراء
- خروج عند إشارة بيع SuperTrend
- إعدادات: فريم، ATR، مضاعف، حجم الصفقة، أقصى مراكز

لوجات Railway: `[ST]`

## محافظ
كما هي — تشغيل/إيقاف، ذكي/يدوي، وقف متحرك.
