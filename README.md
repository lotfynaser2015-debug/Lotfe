# Lotfe — MEXC Portfolio Manager

بوت تليجرام لإدارة محافظ سبوت على MEXC بوضعين منفصلين.

## الأوضاع

| الوضع | السلوك |
|--------|---------|
| **ذكي** | وقف متحرك فقط (يرتفع مع السعر). بدون أوامر TP على المنصة. |
| **يدوي** | TP1/TP2/TP3 أوامر Limit على MEXC + وقف خسارة ثابت يراقبه البوت ويبيع سوق عند الضرب. |

تبديل الوضع من زر **ذكي / يدوي** داخل المحفظة:
- **لا يبيع** العملات
- يحدّث الأوامر والاستوب فقط
- أي ملاحظة تظهر بالعربي في تليجرام وفي لوج Railway

## أزرار المحفظة

- تشغيل / إيقاف
- تحديث الأهداف
- إضافة / حذف عملة
- ذكي / يدوي
- إعادة بناء
- حذف المحفظة

## تشغيل

```bash
pip install -r requirements.txt
python bot.py
# أو Railway: python start.py
```

## متغيرات البيئة
