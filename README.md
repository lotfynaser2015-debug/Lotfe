# MEXC Portfolio Manager

بوت تليجرام لإدارة محافظ متعددة على **MEXC Spot** بنظام **وقف متحرك (Trailing Stop)** وإعادة دخول متكررة.

## المنطق الحالي

1. **شراء** العملات حسب المحفظة
2. **استوب ابتدائي** تحت سعر الدخول (~3% أو حسب ATR)
3. مع صعود السعر → **رفع الاستوب تلقائياً** (لا ينزل أبداً)
4. بعد ربح ≥ 1.2% → الاستوب على **سعر الدخول** (break-even)
5. ربح قوي (≥6% / ≥12%) → مسافة trailing أوسع
6. ضرب الاستوب → بيع فوري + انتظار إعادة دخول
7. **إعادة دخول متكررة** عند رجوع السعر فوق مستوى الاستوب بـ +1% (مش مرة واحدة)
8. تبريد 90 ثانية بين محاولات إعادة الدخول لمنع السبام

## ملغي

- أهداف TP1 / TP2 / TP3 الثابتة على المنصة
- نظام الخبراء ومصادر الإشارات

## المتغيرات

| المتغير | الوصف |
|---------|--------|
