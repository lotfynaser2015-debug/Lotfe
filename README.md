# MEXC Portfolio Manager

بوت تليجرام لإدارة محافظ متعددة على **MEXC Spot** مع أهداف ربح ذكية وTrailing Stop.

## التحديثات الأخيرة

- صفقات أقل من **10 USDT** → هدف واحد فقط (TP1 بنسبة 100%)
- إغلاق كامل تلقائي عند بيع الكمية كلها (مافيش Trailing وهمي بعد البيع الكامل)
- حذف نظام الخبراء بالكامل
- حذف مصادر الإشارات بالكامل
- تنظيف الكود من أي كود غير مستخدم

## المميزات

- محافظ متعددة (حتى 30 عملة لكل محفظة)
- أهداف ربح متعددة (TP1 / TP2 / TP3) + وقف خسارة
- بعد الهدف 1 → الاستوب على سعر الدخول (Break-even)
- بعد الهدف 2 → رفع الاستوب + Trailing للجزء المتبقي
- وضع البامب: عند ربح ≥ 6% يلغى الأهداف الثابتة ويُعتمد على Trailing أوسع
- إعادة دخول تلقائية مرة واحدة بعد ضرب الاستوب (+1.2%)
- أهداف ذكية من ATR + الاتجاه (smart_levels)
- دفاع السوق من BTC (market sense)

## المتغيرات المطلوبة

| المتغير | الوصف |
|---------|--------|
| TELEGRAM_BOT_TOKEN | توكن بوت تليجرام |
| MEXC_API_KEY | مفتاح API من MEXC |
| MEXC_API_SECRET | السر |
| DATABASE_URL | رابط PostgreSQL |
| ADMIN_TELEGRAM_ID | رقمك في تليجرام (مستحسن) |

## التشغيل

```bash
pip install -r requirements.txt
cp .env.example .env
# عدّل .env
python bot.py
```

## التشغيل على Railway

```bash
python start.py
```

## ملاحظات تقنية

- لو الصفقة أقل من **10$** → أمر بيع واحد فقط (100%) عند الهدف 1
- بعد ملء أي هدف: لو الكمية المتبقية ≈ 0 أو الرصيد الفعلي صفر → **إغلاق كامل** والحالة `closed`
- المراقبة كل 45 ثانية عبر `monitor_positions_job`
