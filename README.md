# MEXC Portfolio Manager

بوت تليجرام لإدارة محافظ متعددة على **MEXC Spot** مع وضع تحكم ذكي أو يدوي.

اللوجو الرسمي للمشروع: `assets/lotfe-logo.png`

## المنطق الحالي

1. **الوضع الذكي:** وقف ابتدائي تكيفي حسب ATR، ثم trailing لا ينخفض أبداً.
2. بعد ربح ≥ **4%** في الوضع الذكي → نقل الوقف إلى سعر الدخول، ثم متابعة السعر.
3. ربح قوي (≥6% / ≥12%) → مسافة trailing أوسع.
4. ضرب الاستوب الذكي → بيع فوري + انتظار إعادة دخول.
5. **إعادة دخول متكررة** عند رجوع السعر فوق مستوى الاستوب بـ +1%، مع تبريد 90 ثانية.

## الوضع اليدوي

من زر **وضع التحكم** داخل كل محفظة يمكن اختيار:

- **ذكي:** ATR + trailing + حماية السوق الذكية.
- **يدوي:** TP1 / TP2 / TP3 ووقف الخسارة من إعدادات المحفظة، وتتم مراقبتها دون تغييرها تلقائياً.

يجب إيقاف المحفظة قبل تبديل الوضع ثم استخدام **إعادة بناء المراكز** لتطبيقه على المراكز الحالية.

## ملاحظة التنفيذ

الأهداف والوقف تتم مراقبتها بواسطة البوت وإرسال أمر سوق عند تحقق الشرط؛ لا يتم إنشاء أوامر limit موازية على المنصة لتجنب البيع المزدوج. لذلك يجب أن يبقى البوت والاتصال بالـ API متاحين.

## المتغيرات

| المتغير | الوصف |
|---------|--------|
| TELEGRAM_BOT_TOKEN | توكن البوت |
| MEXC_API_KEY / MEXC_API_SECRET | مفاتيح MEXC |
| DATABASE_URL | PostgreSQL |
| ADMIN_TELEGRAM_ID | رقم الأدمن |

## التشغيل

pip install -r requirements.txt
