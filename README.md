# MEXC Portfolio Manager + Signal Engine

بوت تليجرام متكامل لإدارة محافظ متعددة على **MEXC Spot** + نظام إشارات تنفيذ ذكي.

## التحديثات الأخيرة
- واجهة أجمل وأكثر تنظيماً (قوائم وإيموجي ونصوص أوضح)
- تسريع جلب الأسعار باستخدام `fetch_tickers` دفعة واحدة بدلاً من طلب لكل عملة
- دعم Whale Alert و Arkham تلقائياً داخل محرك الإشارات
- حذف الملفات الزائدة

## المميزات

### 1. زيادة الحد الأقصى للعملات
- من **10** → **30** عملة لكل محفظة.

### 2. نظام الإشارات (Signal Engine)
- إضافة مصادر إشارة (BlackRock / MacroStrategy / WhaleAlert / أي اسم)
- كل مصدر له: حد أدنى للقيمة، أقصى عدد تحويلات، محافظ شراء/بيع، تفعيل/تعطيل، cooldown
- تحليل تلقائي لرسائل Whale Alert و Arkham

### 3. استقبال الإشارات من المجموعة

```
#SIGNAL
Source: BlackRock
Action: BUY
Reason: Withdrawal from Coinbase > 15M | 2 txs
Portfolios: 1,3,5
Size: Full
```

أو بالعربي:

```
إشارة
المصدر: بلاك روك
القرار: شراء
السبب: سحب من كوينبيز أعلى من 15 مليون
المحافظ: 1 3 5
الحجم: كامل
```

## التشغيل على Railway

هذا المشروع يعمل كـ **Worker** طويل التشغيل، وليس كخدمة HTTP. اترك أمر التشغيل:

```bash
python start.py
```

وأضف المتغيرات التالية في Railway:

- `TELEGRAM_BOT_TOKEN`
- `MEXC_API_KEY`
- `MEXC_API_SECRET`
- `DATABASE_URL` (أضف PostgreSQL إلى المشروع ثم استخدم متغير الاتصال)
- `ADMIN_TELEGRAM_ID` (اختياري لكنه مستحسن)

إذا كان البناء ناجحًا ثم توقف الـ Worker مباشرة، افتح Runtime Logs؛ سيظهر اسم أي متغير مطلوب غير موجود.

## طريقة الاستخدام

1. أنشئ محافظك (إضافة عملات + مبلغ)
2. ادخل **📡 مصادر الإشارات** → أضف مصدر
3. حدد أرقام المحافظ للشراء/البيع
4. ابعت رسالة الإشارة في المجموعة
5. البوت ينفذ ويرد بالتقرير

## أهداف الربح ووقف الخسارة (TP/SL)

- من **⚙️ الإعدادات** في البوت تقدر تعدل:
  - نسبة هدف الربح (افتراضي 5%)
  - نسبة وقف الخسارة (افتراضي 3%)
- عند **تشغيل** المحفظة:
  - يشتري العملات
  - يحط أمر **Limit Sell** على MEXC عند سعر الهدف (يظهر في Open Orders)
  - يفعل مراقبة سحابية لوقف الخسارة
- **النظام الذكي (smart_levels.py)**: عند زر التحديث أو إعادة الدخول تُحسب الأهداف من ATR + اتجاه العملة (مش نسب ثابتة فقط).
- بعد الهدف 1 → الاستوب على **سعر الدخول (Break-even)**
- بعد الهدف 2 → الاستوب يُرفع لحماية الربح عند **مستوى الهدف 1** (مش سعر الهدف 2) + **Trailing** للجزء المتبقي
- لو ضرب الاستوب → بيع فوري بسعر السوق ثم **إعادة دخول تلقائية مرة واحدة** عند رجوع السعر +1.2% فوق مستوى الاستوب
- عند **إيقاف** المحفظة: يلغي أوامر الهدف + يبيع الباقي، والمحفظة تفضل محفوظة

## إدارة الاستوبات والإحصائيات

- بعد ضرب الاستوب يتم تسجيل العملة والنتيجة في سجل المحفظة.
- **إعادة الدخول التلقائية** بعد الاستوب (مرة واحدة) عند استعادة +1.2%. الزر اليدوي يبقى متاحاً كاحتياطي.
- زر **🔎 فحص العملات الناقصة** يقارن العملات المسجلة في المحفظة مع الرصيد
  الفعلي على MEXC، ويعرض العملات التي لم تعد موجودة. يمكن تحديد عملة أو أكثر
  ثم تأكيد الشراء في خطوة منفصلة. يتم إعادة الفحص قبل التنفيذ، ولا تُحسب
  العملات المقفولة داخل أوامر البيع كعملات ناقصة.
- عند حذف عملة من المحفظة، يلغي البوت أوامر أهدافها على MEXC أولاً، ثم يبيع
  الرصيد المتاح بسعر السوق. إذا فشل إلغاء أي هدف أو فشل البيع، لا يحذف سجل
  العملة من قاعدة البيانات.
- زر **🧹 تنظيف قاعدة البيانات** يفحص الحالة الفعلية قبل أي حذف. يترك المحافظ
  العاملة والعملات ذات الرصيد أو أوامر البيع القائمة، وينظف فقط المحافظ المغلقة
  بلا أصول، وبيانات المراكز القديمة بلا رصيد، والسجلات اليتيمة. التنظيف يمر
  بتقرير ثم تأكيد، ويعيد الفحص مرة أخرى قبل التنفيذ.
- زر **🔄 تحديث الأهداف** يحسب أهدافاً ذكية لكل عملة (ATR/اتجاه) ويعيد وضع الأوامر
  من غير بيع أي مركز. أنت تضغط الزر يدوياً وقت ما تحب.
- زر **📊 إحصائيات الربح والخسارة** يعرض الربح المحقق من الأهداف والاستوبات،
  والربح/الخسارة غير المحققة للمراكز المفتوحة، والإجمالي.
