# Lotfe — MEXC Spot Bot

محافظ + **اصطياد الانهيار** (يدوي / تلقائي).

## اصطياد الانهيار
داخل المحفظة → **🎯 اصطياد الانهيار**

- **يدوي:** تحدد نسب السلم مثل -10,-20,-30 → أوامر حد شراء لكل عملات المحفظة
- **تلقائي:** تحليل حركة BTC يختار السلم ثم يضع الأوامر
- ميزانية مشتركة تُقسَّم على العملات × المستويات
- إلغاء أوامر الشراء المعلّقة من نفس القائمة

## بيئة
TELEGRAM_BOT_TOKEN, MEXC_API_KEY, MEXC_API_SECRET, DATABASE_URL, ADMIN_TELEGRAM_ID
